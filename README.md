# Z-Profile Site Builder

This repository contains the code for the Flask app running at: <https://wraggelabs.com/z-profile>

The Z-Profile Site Builder is part of the [Z-Profile system](https://wraggelabs.com/z-profile-docs/).

## To use

If you wanted to run this yourself you'd need to set environment variables for:

- `ZOTERO_CLIENT_KEY`
- `ZOTERO_CLIENT_SECRET`
- `ZPROFILE_SECRET_KEY`

The Zotero key and secret can be obtained by [registering an app](https://www.zotero.org/oauth/apps) with Zotero's OAuth service.

You'd also need to `git clone` the [z-profile repository](https://github.com/wragge/z-profile) into the working directory.
